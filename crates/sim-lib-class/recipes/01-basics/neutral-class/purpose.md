# Classes for a language that does not exist yet

The checked `neutral_class_specimens` integration test composes the public class
organ without importing a shipped guest-language type. It proves a hand-written
C3 diamond order; typed precedence, cycle, and budget failures; managed cache
reclamation with an observed ephemeron-clearing receipt; member Shape browsing;
and read construction that reproduces its input values.

Run it with:

```sh
cargo test -p sim-lib-class --test neutral_class_specimens
```

The final ownership specimen inspects both this crate's manifest and its own
source so the example remains a language-neutral composition of public SIM
contracts rather than a hidden adapter to an established guest runtime.
